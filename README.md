# DEO 🦅

Projet fullstack :
- Backend : Node.js / Express / PostgreSQL
- Mobile : Expo / React Native

## Structure
- backend/ → API
- mobile/ → application mobile
- scripts/ → utilitaires
- docker-compose.production.yml → production

## Lancer le backend
cd backend
npm install
npm run dev

## Lancer le mobile
cd mobile
npm install
npm start
